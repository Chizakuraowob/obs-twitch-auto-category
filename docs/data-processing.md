# 遊戲辨識與資料處理清單（0.5.11，2026-10-27）

本文件記錄目前實作，供作者撰寫正式條款與隱私政策，並非法律審查。使用者文件為 [使用者條款](terms.md) 與 [隱私權政策](privacy.md)，版本 `2026-10-27-v6`。已完成首次設定者以獨立視窗確認文件更新，不重跑設定精靈。升級後首次儲存保留原檔備份；讀取失敗阻止寫入並提供還原。登入成功僅嘗試喚回 OBS／工作列提醒，不新增伺服器、瀏覽器控制或 OAuth 回呼端點。

搜尋名稱在停止輸入約 400 毫秒後送至 Twitch，也可按 Enter 立即送出；沒有額外的分類搜尋按鈕，空白輸入不發送請求。靜音模式只在本機保存通知偏好，分類提醒使用無系統提示音的視窗並閃爍 OBS 工作列，不增加外部資料傳送，也不改變系統或其他程式的音量。

登入成功畫面顯示既有 OAuth 驗證結果中的帳號名稱，等待使用者按繼續，不另外查詢頭像或新增保存資料。登出完成提示依本機憑證清除結果顯示；遠端授權撤銷仍依原有流程另外確認，不把本機登出視為遠端撤銷成功。

連接 Twitch 且完成文件同意後，約每 30 秒讀取一次目前帳號的直播分類；與手動重新整理使用相同 Helix API、帳號識別碼與授權，不新增權限或服務。登出／關閉外掛時停止，同步中不重複送出請求；同分類已有封面網址時會沿用。這項讀取只更新面板，不會更改 Twitch 分類。「最後確認」使用成功讀取分類的時間，不以封面載入或失敗請求冒充成功確認。遊戲名稱聯網查詢仍需另外開啟，精靈與設定頁使用同一個偏好。

## 本機來源與保存

| 資料 | 來源、用途與保存 |
|---|---|
| 程序檔名與前景程序 | Windows 程序快照；分類比對、提醒去重及遊戲退出計時。只留工作階段記憶體，不上傳。 |
| 可見視窗標題、類別、程序路徑、父程序名稱 | 自動掃描只讀符合條件的前景、已記住或待確認程序；手動「新增遊戲」會列出符合條件的可見視窗供選擇。標題最多 256 字，過長則不納入。父程序只作線索。原始路徑及未確認資料不寫入設定、不上傳。 |
| 已確認視窗規則 | `settings.json` 保存程序、視窗類別、分類 ID／名稱與路徑 SHA-256 指紋，或確認的標題／字面前綴。可標記不是遊戲、改分類、忘記。指紋不等同匿名化；標題可能含私人內容。 |
| Steam 遊戲庫 | HKCU Software/Valve/Steam 的 SteamPath、libraryfolders.vdf、appmanifest_*.acf；名稱、App ID、目錄只在本機比對。 |
| Epic 遊戲庫 | ProgramData/Epic/EpicGamesLauncher/Data/Manifests/*.item；不讀 Epic Token。 |
| GOG 遊戲庫 | HKLM SOFTWARE/GOG.com/Games 與 WOW6432Node 對應位置；不讀 GOG Token。 |
| 遊戲庫分類對應、忽略項目與舊程序規則 | 保存在 `settings.json`；「我的遊戲」整合顯示三種既有資料，不清除舊設定。 |
| OAuth Token | Windows Credential Manager；不寫入設定 JSON、GitHub 請求或活動文字。 |
| 偏好、收藏、同意紀錄 | OBS 外掛設定目錄；包括聊天建議開關與秒數、自動檢查更新開關、略過版本。 |
| 更新檔 | 設定目錄 `updates` 子目錄，下載完成保留 MSI；安裝成功後刪除，取消／失敗保留。安裝助手與記錄保留供排錯。 |

不讀取遊戲記憶體、命令列、存檔或畫面，不遞迴掃描磁碟。不提高程序權限；路徑不可讀時允許使用確認過的視窗身分。已知遊戲庫約每 60 秒刷新，程序約每 3 秒掃描，拒絕遠端遊戲庫目錄。

一般未確認視窗不再彈出確認要求，也不阻止 Just Chatting 倒數。手動確認後才加入遊戲規則。未知前景仍可阻止背景遊戲被自動選中，但不會因此取消聊天提醒。聊天提醒預設 90 秒，可調 15～600 秒或關閉；只手動確認套用。選擇「這次不再提醒」或關閉提醒視窗後，本次遊戲結束不再詢問，下一次偵測到遊戲並結束後才重新提醒；只在工作階段記憶體記錄。同一程序的遊戲分類提醒保留至程序連續消失 60 秒；不持久化。

## Twitch 連線

- OAuth、手動分類搜尋、更新與讀回確認連線 Twitch 官方服務；分類圖片連線 Twitch CDN。
- 分類圖片只解碼內容為 PNG 或 JPEG 的檔案，其他格式不顯示封面；圖片大小與尺寸仍受限制。
- 遊戲庫名稱自動查詢預設關閉。啟用、同意且登入後，只將執行中遊戲的名稱及 OAuth 必要資訊送到 `api.twitch.tv/helix/games`；僅採用唯一同名分類，最多保存 1,000 筆對應。
- 不上傳程序清單、路徑、父程序、指紋、未知標題或完整遊戲庫。手動搜尋會送出使用者輸入的文字。
- Twitch 可取得連線 IP、請求時間與相關帳號資訊，依其政策處理；外掛不替第三方承諾保存期限。
- 開發者模式禁止建議的實際分類寫入，但手動搜尋、收藏套用及已允許的名稱查詢仍可能連線。

## GitHub 更新連線

- 作者指定來源：`Chizakuraowob/obs-twitch-auto-category`。來源內建於發行版，沒有使用者任意輸入更新網址的入口。
- 外掛的 Twitch、GitHub 與分類圖片請求停用 HTTP/2，以降低受影響 Qt 版本的 HTTP/2 崩潰風險；目的地、傳送資料與 TLS 驗證不變。
- 手動按下檢查才連線；自動檢查預設關閉，開啟後在啟動時檢查一次，沒有持續輪詢。
- 檢查端點：`https://api.github.com/repos/Chizakuraowob/obs-twitch-auto-category/releases/latest`。只接受穩定版本，不接受草稿、預覽版或降版。
- 不提供 GitHub 登入、不傳送 Twitch Token、Client ID、程序或遊戲資料。GitHub 可取得 IP、User-Agent 與一般請求資訊；版本比較在本機完成。
- 只有使用者按下載才取得 MSI。初始網址必須符合指定儲存庫的 Release 資產路徑；HTTPS 重新導向限 `github.com`、`release-assets.githubusercontent.com`、`objects.githubusercontent.com`，最多 5 次，總下載期限 120 秒、上限 100 MB。
- 核對 GitHub API 資產的 SHA-256 與大小；不完整或不符的下載不保留。雜湊由同一 GitHub 來源提供，不是獨立的作者身分保證。
- Windows 簽章檢查僅使用本機快取，不為此查詢外部撤銷服務，也未配置作者簽章身分釘選。下載前及驗證完成後分別要求確認，第二次確認才啟動接續安裝；未簽章不會繞過 Windows 安全限制。
- 更新說明以 Markdown 顯示，停用 HTML 與圖片／外部資源載入；只有點擊 HTTPS 連結才交由預設瀏覽器開啟。
- API 回應、更新說明與下載進度只留記憶體；更新開關、略過版本和完成的 MSI 會保存於本機。

### 接續安裝

更新接續程序（0.5.8）：檢查直播、錄影、重播緩衝與虛擬攝影機均已停止，再正常關閉 OBS。獨立本機 PowerShell 助手最多等待 120 秒，確認 OBS 已退出且無其他 OBS 後，再次核對 SHA-256 並啟動 Windows Installer。使用單次執行原則參數執行內建腳本，不更改系統執行原則、憑證信任或 Smart App Control。安裝精靈、UAC 與安全提示保留，不強制終止 OBS、不熱替換 DLL。Windows 政策仍可能阻止執行。成功代碼 0、1641、3010 才刪除此次 MSI；取消、失敗、OBS 未退出或雜湊不符時保留。updates 內的助手、.install.log、.update-error.log 不上傳，可自行刪除；安裝後由使用者重開 OBS。

## 刪除與匯出

「我的遊戲」可更改、忽略或忘記單筆資料。「清除分類對應快取」保留收藏與視窗規則；「清除本機資料」重設偏好與規則並嘗試撤銷帳號授權。「清除本機資料」不會刪除已匯出的 JSON、既有設定備份及取消／失敗後保留的 MSI，請自行管理。

規則匯入／匯出只包含已確認視窗規則，尚不包含舊程序規則與遊戲庫快取。匯入限制 1 MB／500 筆，驗證格式、不執行程式碼或正規表示式、不覆寫衝突。匯出不含 Token 或 Client ID，但可能含私人標題／路徑指紋。

沒有遙測、作者後端、完整遊戲庫回傳或第三方遊戲資料庫下載。不能保證所有遊戲、特殊啟動器或相同可見身分都能自動辨識。

設定保護（0.5.3）：設定記錄 savedByVersion；新版第一次儲存會在同一目錄建立 settings.json.backup-時間。備份還原前保留 settings.json.before-restore-時間，不自動刪除這些備份；內容可能含私人標題與指紋。此機制不傳送資料至外部。
